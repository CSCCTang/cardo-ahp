# 输入准备（cardo-ahp）

## 文件清单

| 文件 | 必需 | 形态 |
|---|---|---|
| 专家问卷 / 打分表 | 是 | xlsx，一格一个判断，按表头填写 |
| 候选方案清单 | 是 | xlsx，方案名 + 说明 |
| 专家名单 | 否 | xlsx，用于按专家归档 |

## 最小样例

- `skills\cardo-ahp\assets\inputs\专家名单-空白.xlsx`
- 问卷与方案清单按表头自建；表头就是一格一个判断（行=指标，列=指标）。

## 摆放

```
D:\proj\ahp-01\
  输入文件\问卷.xlsx
  输入文件\方案清单.xlsx
```

## 不要放什么

- 多个版本的问卷混放（先确定最终版）。
- 图片版打分表（请录成 xlsx）。
