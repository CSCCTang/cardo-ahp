# 02 · 专家问卷生成（AHP 流程第 2 步）

## 何时使用
指标体系确认后、专家函询前。生成空白问卷发给专家；回收后放入 `输入文件/02-专家问卷（已回收）` 交给第 03 步。

## 输入 / 输出
- 输入：`Skills/02-问卷生成/规则/指标体系.yaml`、`标度与口径.yaml`
- 输出（**领料区，人可见**）：`输入文件/02-专家问卷（待发放）/AHP专家问卷-专家1..N.xlsx`
- 输出（过程归档）：`过程文件/02-问卷生成/问卷空白/AHP专家问卷-专家1..N.xlsx` + `问卷清单.json`

> 两个位置内容相同：领料区是给人拿去发的那份，过程目录是留痕。
> 只有 xlsx 进领料区；机读的 `问卷清单.json` 留在过程文件里（输入侧不放机读文件）。

## 执行命令（在 CardoAHP 根目录执行）

```powershell
python Skills/02-问卷生成/scripts/gen_questionnaire.py generate `
  --out "过程文件/02-问卷生成/问卷空白" `
  --experts 5 `
  --scale scale_0_1 `
  --criteria-scale scale_1_9 `
  --project-name "某某片区改造项目" `
  --no-timestamp

# 复制到领料区（只复制 xlsx；已存在的不覆盖）
# —— 实际由 pipeline.py 第 02 步自动完成，勿手工复制

# 按回收问卷生成输入侧人读登记表（xlsx，替代原 JSON 问卷清单）
python Skills/02-问卷生成/scripts/专家名单导出.py `
  --dir "输入文件/02-专家问卷（已回收）"
```

**项目名一律用占位的「某某片区改造项目」**：问卷要匿名，避免专家被项目背景锚定判断；
真实项目名只出现在成果文件里。因此**发卷这一步不需要项目全称**。

已存在 `专家名单.xlsx` 时不会覆盖（保留人工填写的角色），需重写加 `--force`。
机读清单仍在 `过程文件/02-问卷生成/问卷空白/问卷清单.json`（过程产物，不进输入目录）。

## 问卷格式（行业通行做法）
- 每个专家一个 xlsx：封面 / 准则层 / 指标层（4 个矩阵分区）/ 自动校验。
- 只填灰色上三角：准则层填 1/9~9（1-9 标度）；指标层填 0.1~10（0.1-1 标度）；下三角自动互反。
- 30 个上三角输入 = 准则矩阵 6 + 4 个指标矩阵各 6。
- 每份问卷封面有标度说明与填写规则；工作区根目录的 `怎么填.md` 另有逐格说明（面向发卷人）。

## 闸门
- 专家数 5-7（规则 minExperts=5/maxExperts=7）；等权，不设专家权重。
- 领料区份数 = 专家数。
- 本工作区已回收的 5 份问卷在 `输入文件/02-专家问卷（已回收）`，专家构成见同目录 `专家名单.xlsx`。

## 调优点
- 专家人数：改 `--experts`；加发/补收：把新问卷放进已回收目录即可，03/04 步自动识别。
- 措辞、封面、自动校验阈值：改 `scripts/_survey_lib.py`（本 skill 自包含副本）。
