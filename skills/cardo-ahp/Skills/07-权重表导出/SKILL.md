# 07 · 权重表导出与回读校验（AHP 流程第 7 步）

## 何时使用
第 05 步 CR 全部通过（第 06 步无需校准或校准后重算通过）后，形成对外交付的权重表。

## 文件边界
- 输入：`过程文件/05-权重与一致性/权重表.json`、`输入文件/01-AHP四准则模板/4 层次分析法AHP四准则模板.xlsx`（只读，sha256 基线 9E97…27C0）
- 成果（交付）：`成果文件/AHP权重表.xlsx` —— 第 09 步装配时归位为
  `成果文件/成品版/AHP权重表/AHP权重表_成品版.xlsx`，并另存 `成果文件/内部件/AHP权重表/AHP权重表_溯源版.xlsx`（附「内部核对」页）
- 过程（机读）：`过程文件/07-权重表导出/权重表.json`、`回读校验报告.json`

## 执行命令（在工作区根目录）

```powershell
python Skills/07-权重表导出/scripts/ahp_export.py export `
  --weights "过程文件/05-权重与一致性/权重表.json" `
  --out "成果文件/AHP权重表.xlsx" `
  --out-json "过程文件/07-权重表导出/权重表.json" `
  --template "输入文件/01-AHP四准则模板/4 层次分析法AHP四准则模板.xlsx" `
  --no-timestamp

python Skills/07-权重表导出/scripts/ahp_export.py verify `
  --file "成果文件/AHP权重表.xlsx" `
  --json "过程文件/07-权重表导出/权重表.json" `
  --template "输入文件/01-AHP四准则模板/4 层次分析法AHP四准则模板.xlsx" `
  > "过程文件/07-权重表导出/回读校验报告.json"
```

## 闸门
- verify 对账通过：xlsx 中 4 准则权重、16 局部/综合权重与过程 JSON 完全一致；Σ综合=1。
- 模板原件只读：导出前后 sha256 不变，交付件另存。
- 成果目录不得出现 `权重表.json`（机读件只在过程文件）。

## 调优点 / 已知边界
- 版式对齐（合并格、批注、印刷示例值识别）是已知边界；本课题模板固定可稳定写入。
- 写入列位、表头样式：改 `scripts/_export_lib.py`。
