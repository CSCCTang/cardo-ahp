# 08 · 候选方案打分与综合评分（AHP 流程第 8 步）

## 何时使用
权重表定稿后，对候选方案（如拆除重建 / 微更新 / 功能置换）打分评级，形成投资排序结论。
换评分时只重跑本步与第 09 步（`pipeline.py run --from 08`）。

## 文件边界
- **输入（人填）**：`输入文件/03-方案打分表/AHP方案评分表.xlsx`
- **过程（机读）**：`过程文件/08-方案打分/打分.json`（由 xlsx 自动转换，勿手改）、`评分表.json`、`评分结论.md`
- **成果（交付）**：`成果文件/AHP方案评分结论.xlsx`

## 评分表版式（xlsx = 事实源）
- Sheet「方案信息」：序号 | 方案编号（S1/S2…）| 方案名称 | 方案说明
- Sheet「方案评分表」：第 3 行表头；A序号 B准则 C指标 D指标ID E含义 F综合权重 G评分标准
  H..各方案得分（黄色格为待填，0-10，1 位小数） 其后 依据-方案一/二/三
- 只改**得分**与**依据**列；不要改「指标ID / 综合权重 / 评分标准」，否则换算时对不上。
- 末尾「综合得分」行是 SUMPRODUCT 展示公式，以引擎 JSON 结果为准。

## 执行命令（在工作区根目录）

```powershell
# 8.1 空白模板（仅新项目首次；已有评分表则跳过）
python Skills/08-方案打分/scripts/gen_scoresheet.py `
  --weights "过程文件/05-权重与一致性/权重表.json" `
  --project-name "某某片区改造项目" `
  --out "输入文件/03-方案打分表/AHP方案评分表.xlsx"

# 8.2 xlsx（人填）→ 过程 JSON（引擎读）；越界/非数字/未知指标会逐行报错
python Skills/08-方案打分/scripts/xlsx转打分.py `
  --xlsx "输入文件/03-方案打分表/AHP方案评分表.xlsx" `
  --out "过程文件/08-方案打分/打分.json"

# 8.3 加权评分（10 分制、评级、排序）
python Skills/08-方案打分/scripts/score_project.py score `
  --weights "过程文件/05-权重与一致性/权重表.json" `
  --scores "过程文件/08-方案打分/打分.json" `
  --out "过程文件/08-方案打分/评分表.json" --no-timestamp

# 8.4 导出交付用评分结论 xlsx
python Skills/08-方案打分/scripts/评分结论导出.py `
  --scores "过程文件/08-方案打分/评分表.json" `
  --out "成果文件/AHP方案评分结论.xlsx" `
  --project-name "某某片区改造项目"
```

## 闸门与红线
- 转换成功（退出码 0）；方案数（xlsx = 出分）一致；每个方案 composite ∈ [0,10]；名次连续。
- 评级：[9,10] 优秀 / [7,9) 良好 / [6,7) 一般 / [0,6) 不可行，左闭右开。
- 引擎只加权，不替人拍分；缺必填项则该方案不出分并点名，禁止用 0 分掩盖缺数据。
- 权重与评分必须同源：权重取第 05 步产物，评分取本工作区 xlsx。

## 调优点
- 评级阈值、缺项重归一、必选/可选：改 `规则/指标量化分档.yaml` 与 `scripts/score_project.py`。
- 评分表版式/配色/列宽：改 `scripts/gen_scoresheet.py`（同时要同步 `xlsx转打分.py` 的列约定）。
- 结论 xlsx 的工作表与列：改 `scripts/评分结论导出.py`。
