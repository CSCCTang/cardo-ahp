# 05 · 权重计算与一致性检验（AHP 流程第 5 步）

## 何时使用
聚合通过后。先转矩阵集，再算权重与 CR；CR 不通过时走第 06 步校准后回本步重算。

## 输入 / 输出
- 输入：`过程文件/04-多专家聚合/群体矩阵.json`
- 输出（过程归档）：
  - `过程文件/05-权重与一致性/矩阵集.json`（**full 形态**：群体互反矩阵原样写出）
  - `过程文件/05-权重与一致性/全矩阵/*.json`（供 06 校准）
  - `过程文件/05-权重与一致性/权重表.json`（cardo/ahp-weights/v1）
  - `过程文件/05-权重与一致性/一致性结果.md`、`权重表.md`

## 执行命令（在 CardoAHP 根目录执行）

```powershell
# 5.1 群体全矩阵 → full 形态矩阵集（逐格校验正性/互反/对角线后原样参与计算）
python Skills/05-权重与一致性/scripts/聚合转矩阵集.py `
  --agg "过程文件/04-多专家聚合/群体矩阵.json" `
  --out-dir "过程文件/05-权重与一致性"

# 5.2 双算法权重（几何平均 + 特征值；含逐矩阵 CR、综合权重）
python Skills/05-权重与一致性/scripts/ahp_calc.py weights `
  --matrix-set "过程文件/05-权重与一致性/矩阵集.json" `
  --format json --no-timestamp > 过程文件/05-权重与一致性/权重表.json

# 5.3 一致性批量检验
python Skills/05-权重与一致性/scripts/ahp_calc.py consistency `
  --matrix-set "过程文件/05-权重与一致性/矩阵集.json" `
  --format md --no-timestamp > 过程文件/05-权重与一致性/一致性结果.md
```

## 为什么是 full 而不是列向量（2026-10-30 修正）

群体矩阵是 n×n 互反矩阵，**首列不足以还原整张矩阵**：首列还原 `a_ij = v_i/v_j`
只在「矩阵完全一致（传递性成立）」时才等于原矩阵。真实专家判断必然有分歧（CR>0），
实测首列还原后矩阵元素最大偏差 0.26、准则层权重最大偏差 **0.037（3.7 个百分点）**，
且首列元素常 >1 触发 scale_0_1 输入域 [0.1,1] 越界报错、整链在 05 步中断。
故群体矩阵一律以 full 形态写出——05 步权重与 04 步聚合报告口径完全一致（偏差 1e-13）。

## 闸门
- 5/5 矩阵 CR<0.1（RI：n=4 取 0.90）。
- 几何平均与特征值两算法权重差 Δ：判据为 **Δ ≤ max(1e-12, CR)**，不是绝对 1e-12。
  两法对不一致矩阵给出不同近似解，差值与不一致度同阶（实测 Δ/CR 稳定在 0.06~0.16）；
  写死 1e-12 等价于要求「矩阵完全一致」，会让 09 步对任何真实项目必 FAIL。
  CR=0（完全一致矩阵）时仍要求精确相等。
- 综合权重 Σ=1；准则权重与 04 步聚合报告一致。
- CR 不通过 → 第 06 步。

## 调优点
- 计算实现：`scripts/_ahp_lib.py`（双算法、RI、幂等输出）。
- 权重结构只由判断决定；要改权重只能改专家判断，不得在权重表上直接改数。
